🎯 关键词优化矩阵

🟢 高转化词
转化率 ≥ 5% 且 ACOS ≤ 毛利率
操作：加价 10%-15%，放量
🟡 潜力词
点击量高但转化率低（1%-5%）
操作：优化 Listing，暂不加价
🟠 观察词

操作：下调出价 20%，观察 3-5 天
🔴 无效词

✅ 活动提报检查清单

  • 📦 库存检查
    活动产品库存 ≥ 预估销量 × 1.5（安全系数）
    在途库存可在活动结束前到仓
    无缺货风险（可售天数 ≥ 活动天数 × 2）
  • 💰 价格/折扣检查
    折扣力度符合平台门槛（大促要求 ≥ 10% off）
    划线价 > 销售价
    活动价覆盖所有成本后仍有利润
    近30天最低价合规，不违反平台政策
  • ⭐ 店铺评分检查
    店铺星级 ≥ 4.0 ★（平台最低门槛）
    近30天 ODR（订单缺陷率）≤ 1%
    近7天无严重违规通知
  • 📋 产品合规检查
    产品在允许参与的类目内
    Listing 完整（标题/描述/图片/属性）
    无侵权风险（商标/专利/版权）
    产品评分 ≥ 4.0 ★（如有要求）

📐 利润率计算公式

毛利润 = 销售收入 - 产品成本
平台费用 = 佣金(通常8-15%) + 固定费用
广告成本 = 广告总支出
物流成本 = FBA费用 / 自发货运费 + 包装
退换货损耗 = 退货率 × (产品成本 + 往返运费)
净利润 = 销售收入 - 产品成本 - 平台费用 - 广告成本 - 物流成本 - 退换货损耗
